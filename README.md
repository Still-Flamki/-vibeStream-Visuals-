# VibeStream Visuals

Welcome to VibeStream Visuals, an application that transforms your audio tracks into mesmerizing, interactive 3D visual experiences.

This project, built with Next.js and Firebase Studio, allows users to not only enjoy pre-built audio-reactive visualizations but also to create their own custom 3D scenes from scratch.

## Key Features

- **Dynamic Visualizations**: A curated library of audio-reactive visuals, from particle galaxies to geometric tunnels, that pulse and react to your music in real-time.
- **AI-Powered Mood Detection**: An intelligent system analyzes the mood of your audio track (happy, dark, chill, energetic) to automatically tailor the visual color palette.
- **Interactive Studio Mode**: A built-in 3D scene editor where you can:
    - Add and delete objects.
    - Change object shapes (cubes, spheres, cones, etc.).
    - Manipulate object position, rotation, and scale.
    - Set custom colors for objects and the scene background.
- **Custom Scene Integration**: Scenes created in the Studio can be used as a custom visualization in the main player, reacting to the music just like the presets.
- **High-Quality Exports**: Record your audiovisual creations and export them as high-quality video files.

## Tech Stack

- **Frontend**: Next.js, React, TypeScript
- **UI**: ShadCN UI Components, Tailwind CSS
- **3D Graphics**: Three.js / react-three-fiber
- **Audio Processing**: Tone.js
- **Generative AI**: Genkit for mood analysis
