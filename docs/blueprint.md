# **App Name**: VibeStream Visuals

## Core Features:

- Audio Upload & Streaming: Upload local audio files or stream directly from Spotify/YouTube (via URL input).
- 3D Visualizer: Render dynamic 3D graphics using Three.js based on live audio data.
- Interactive Controls: Allow users to rotate, zoom, and click/drag to manipulate visual elements in real-time.
- AI Mood Detection: Incorporate an AI tool to analyze music and auto-adjust color palettes and shapes to match the vibe (happy, dark, chill).
- Social Sharing: Enable users to export visuals as MP4/GIFs and directly share on social media platforms, or embed visualizations.

## Style Guidelines:

- Primary color: Saturated purple (#A020F0) to evoke creativity and music, suggesting energy and synesthesia.
- Background color: Very dark purple (#0A030F), almost black, to emphasize brightness and contrast.
- Accent color: Cyan (#00FFFF) to contrast sharply with the purple hues.
- Body and headline font: 'Space Grotesk' sans-serif, suitable for both headlines and body text. If longer text is anticipated, use this for headlines and 'Inter' for body. 
- Code font: 'Source Code Pro' for any displayed code snippets. 
- Use simple, outlined icons for interactive controls, keeping a futuristic aesthetic.
- Implement smooth transitions and particle effects that respond directly to audio frequencies and user interaction.
